# GRACE — Grism Reionization And Cosmic Evolution Survey

**Nancy Grace Roman Space Telescope · Cycle 1 Approved Program 2003**  
**Program type:** General Astrophysics Survey (GAS), Large  
**Science category:** Intergalactic Medium  
**Principal Investigator:** Sangeeta Malhotra (NASA Goddard Space Flight Center)  
**Approved time:** 420.9 hours  
**Collaborators:** [Full co-investigator list and affiliations on the official program page](https://roman.ipac.caltech.edu/cycle1-approved-programs/2003)

### Main science deliverables

- Measurements of the abundance of **z = 7–10 Lyman-alpha emitters** to constrain cosmic reionization.
- A three-dimensional map of galaxies, protoclusters, and the cosmic web at **z = 1.5–3**.
- Resolved and population-level constraints on star formation, enrichment, and environmental effects.
- Approximately **290,000 emission-line redshifts** to improve faint-galaxy photometric-redshift calibration.
- Studies of faint AGN, little red dots, and Galactic M/L/T/Y dwarfs.
- A pilot study of kinematic lensing and opportunities for spectroscopic time-domain investigations.
- A deep, repeatedly observed community field for testing Roman grism systematics.

### Observing plan at a glance

| Parameter | Planned observations |
| --- | --- |
| Target field | Chandra Deep Field South (CDFS) |
| Instrument | Roman WFI grism and direct imaging |
| Full-depth grism area | **1.5 deg²** at **>40 h** on-source |
| Wider grism area | **2.4 deg²** at **>10 h** on-source |
| Emission-line sensitivity | **1 × 10⁻¹⁷ erg cm⁻² s⁻¹** (5σ, full-depth area) |
| Mosaic | Six pointings in a circular pattern |
| Position angles | **48** |
| Observation configurations | `SP_500_16`, `BOXGAP9_1` |
| Imaging filters | **Y106, J129, H158, F184** |
| Imaging exposure | **3 ks per filter** |
| Imaging limits | **27.1–27.9 mag** (5σ) |
| Grism exposure request | **360 hours** |
| Imaging exposure request | **20 hours** |
| Total with APT overheads | **≈421 hours** (approved **420.9 hours**) |
